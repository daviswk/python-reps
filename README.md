# python-reps
Daily Python Exercises for becoming a problem solver.

## The Ten Rules of Engagement (non-negotiable)
1. AI assistants and autocomplete OFF during Blocks A and B. No Copilot, no Claude, no IntelliSense-completed lines. The skill being built is recall under pressure; you cannot build it while something else finishes your lines. (During Block C, plain autocomplete is fine; AI may review your finished code, never write it.) The reps repo's committed settings enforce this automatically in any codespace opened on it.
2. The struggle timer: 25–30 minutes minimum before looking at any hint on a problem. Discomfort is the mechanism.
3. After solving (or failing): study the best solution, close it, rewrite from scratch. Reading a solution ≠ learning it. Rewriting it cold = learning it.
4. Everything failed or slow goes in MISTAKES.md with the pattern, the wrong turn, and the one-line insight.
5. Re-solve at +2 days, +7 days, +21 days. Sunday runs the re-solve queue. A problem isn't "done" until it's been re-solved cold once.
6. Time-box everything. Easy 15 min, medium 30, hard 45. When time expires, that's data, not failure — journal it and move on.
7. Commit every session. Small commits, working state, real messages. Your contribution graph should show the habit because the habit is real — never fake it.
8. One project deep beats five shallow. Resist starting new repos mid-phase. New ideas go in SOMEDAY.md.
9. Read code weekly (Phase 3 onward): one Saturday hour in excellent source — stdlib, requests, httpx, rich.
10. Ship on a schedule, not when "ready." Version tags go out on the listed week even if imperfect. Imperfect-and-public beats perfect-and-private.
