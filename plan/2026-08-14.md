## Block 2 — Install v2 (~15 min)
(You likely did this to read this file — confirm the tail end.)
4. `git status` should show the new files: `plan/`, `tools/plan.py`, `tests/test_plan_tool.py`, `MASTERY_PLAN_V2.md`, `PRINCIPLES.md`, `.devcontainer/` changes.

## Block 3 — Rebuild + verify (~20 min, mostly waiting)
7. Command Palette → "Codespaces: Rebuild Container". Longer than last time (it's installing Go) — get water.
8. Open a NEW terminal. Verify, in order:
   - `go version` → prints a version
   - `bootdev --version` → prints a version. If "command not found": `export PATH="$HOME/go/bin:$PATH"` then retry; if still missing, run `go install github.com/bootdotdev/bootdev@latest` and retry.
   - `today` → prints this very file. (If the alias is missing: `source ~/.bashrc`, or use `uv run python tools/plan.py`.)
9. `uv run pytest` → the plan-tool tests pass alongside your existing ones. `uv run ruff check .` and `uv run mypy .` → clean. The gauntlet blesses the new tool.

## Block 4 — boot.dev login (~10 min)
10. Create/sign into your account at https://www.boot.dev in your browser (your credentials, your click-throughs).
11. In the codespace terminal: `bootdev login` — it prints a URL; open it, and paste the token it gives you back into the terminal. One-time.
12. Open https://www.boot.dev/courses/learn-git in the browser and start the course.

## Block 5 — Learn Git, Chapter 1: Setup (~30 min)
13. Work chapter 1 with the browser (lesson text) and the codespace terminal (commands) side by side.
14. IMPORTANT: when the course has you create practice repos, do it in your home directory, not inside python-reps — `mkdir -p ~/gitcourse && cd ~/gitcourse`. Nested repos cause haunted-house behavior. Course work lives in `~/gitcourse`; only notes come back to this repo.
15. When a lesson gives you a `bootdev run` / `bootdev submit` command, run it exactly as shown from the directory the lesson expects.
