**The question:** what's the mean body mass of Adelie penguins — with honest uncertainty?

1. Colab → open `runway02_penguins.ipynb` → **Run all** → markdown cell: `## Bootstrap confidence interval`.
2. Cells:
   ```python
   masses = clean.loc[clean["species"] == "Adelie", "body_mass_g"].to_numpy()
   masses.mean(), len(masses)
   ```
   ```python
   boot = np.array([rng.choice(masses, len(masses)).mean() for _ in range(10_000)])
   lo, hi = np.percentile(boot, [2.5, 97.5])
   lo, hi
   ```
   ```python
   plt.hist(boot, bins=60)
   plt.axvline(lo, color="red", linestyle="--")

   plt.title("bootstrap distribution of the mean, 95% CI marked")

   ```
