## Block C — Notebook 01: law of large numbers (60 min)

1. Colab → open `runway01_randomness.ipynb` from GitHub.
2. Markdown cell: `## Law of large numbers`.
3. Cells:
   ```python
   import numpy as np
   import matplotlib.pyplot as plt

   rng = np.random.default_rng(42)
   rolls = rng.integers(1, 7, 10_000)
   running = np.cumsum(rolls) / np.arange(1, 10_001)
   ```
   ```python
   plt.figure(figsize=(10, 4))
   plt.plot(running)
   plt.axhline(3.5, color="red", linestyle="--")
   plt.xlabel("number of rolls")
   plt.ylabel("running mean")
   plt.title("die rolls: running mean converging on 3.5")
   plt.show()
   ```
4. The zoom: same plot but only `running[:100]` — chaos up close, calm from far away. Two cells, both labeled.
