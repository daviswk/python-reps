## Long block — Notebook 01 stretch: the distribution zoo (2h)

1. Colab → open `runway01_randomness.ipynb` → markdown cell: `## The distribution zoo (stretch)`.
2. Cells:
   ```python
   import numpy as np
   import matplotlib.pyplot as plt

   rng = np.random.default_rng(42)
   u = rng.uniform(0, 1, 10_000)
   n = rng.normal(0, 1, 10_000)
   b = rng.binomial(20, 0.3, 10_000)  # 20 tries, 30% success each
   p = rng.poisson(3, 10_000)  # rare events, avg 3 per window
   ```
   ```python
   fig, axes = plt.subplots(2, 2, figsize=(10, 8))
   for ax, data, name in zip(
       axes.flat,
       [u, n, b, p],
       ["uniform(0,1)", "normal(0,1)", "binomial(20, 0.3)", "poisson(3)"],
   ):
       ax.hist(data, bins=50)
       ax.set_title(name)
   plt.tight_layout()
   plt.show()
   ```
