## Long block — flashdown: first real deck (2h)

**Goal:** `uv run python -m flashdown MISTAKES.md -o deck.tsv` produces a file Anki actually imports.

1. Tests FIRST for the TSV traps — add to `tests/test_flashdown.py`, watch each fail, then implement in `flashdown/writer.py`:
   ```python
   from flashdown.writer import to_tsv


   def test_writes_front_tab_back() -> None:
       assert to_tsv([("front", "back")]) == "front\tback\n"


   def test_escapes_tabs_inside_text() -> None:
       assert "\t" not in to_tsv([("a\tb", "c")]).split("\t")[0]


   def test_flattens_newlines_inside_text() -> None:
       assert to_tsv([("a\nb", "c")]).count("\n") == 1
   ```
   (Simplest correct moves: replace inner tabs with spaces, inner newlines with `" / "`.)
2. Wire `flashdown/__main__.py`: read the source file → `parse_mistakes` → `to_tsv` → write to `--out`. Print a summary line: `wrote N cards -> deck.tsv`.
