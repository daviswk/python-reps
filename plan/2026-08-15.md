# Sat Aug 15 — Week 0, Day 2: First reps, new style

Time: ~2.5h · Theme: the CodingBat loop (solve → re-type → gauntlet) + git repositories.

## Block 1 — CodingBat kickoff (~50 min)
1. Open https://codingbat.com/python — create an account (top-right) so progress saves.
2. Open Warmup-1: https://codingbat.com/python/Warmup-1
3. Solve the first EIGHT, in order: sleep_in, monkey_trouble, sum_double, diff21, parrot_trouble, makes10, near_hundred, pos_neg. Type in the site editor, hit Go, read the test table. Red rows are information, not judgment — fix and Go again.
4. THE ENCODING STEP (this is the whole point): back in the codespace, create `codingbat/warmup_1.py`. Without looking at the site, re-type each solved function from memory — WITH type hints, e.g. `def sleep_in(weekday: bool, vacation: bool) -> bool:`. Add two `assert` lines under each (inside a `def check() -> None:` at the bottom that runs them, called under `if __name__ == "__main__":`).
5. `uv run python codingbat/warmup_1.py` → silence means passing. `uv run ruff check .` + `uv run mypy .` → clean.
6. Blanked on one while re-typing? That's the system finding a gap: peek, close, re-type again. Note it in MISTAKES.md.
7. Commit: `feat: codingbat warmup-1 first 8`

## Block 2 — Learn Git, Chapter 2: Repositories (~40 min)
8. `cd ~/gitcourse`, continue the course in browser + terminal. This chapter overlaps your Day-2 four-places model — enjoy how much you already recognize, and notice what's new.
9. One "why" line in LOG.md afterward (Principle 5): why does git separate staging from committing?

## Block 3 — Profile README (~25 min)
10. On github.com, open your `YOURNAME/YOURNAME` repo (create it if Day-6 never happened: new repo named exactly your username, Add README).
11. Press `.` to edit in github.dev: three honest lines + "Currently: a 36-week deep-work Python program (v2)" + a link to python-reps. Commit from the Source Control panel.

## Block 4 — Review ritual, v2 debut (~15 min)
12. In LOG.md: what shipped this week (a lot — the whole v2 system), what confused you, one thing to carry forward.
13. Skim PRINCIPLES.md once, slowly. It's short on purpose.
14. Push everything. `git status` clean. Stop the codespace.
