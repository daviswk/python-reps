## Block C — Notebook 02: the Central Limit Theorem (60 min)

**Goal:** the most important picture in statistics, drawn by you.

1. Colab → open `runway02_penguins.ipynb` → **Runtime → Run all** → markdown cell: `## The Central Limit Theorem`.
2. A deliberately SKEWED population — nothing normal about it:
   ```python
   import numpy as np
   import matplotlib.pyplot as plt

   rng = np.random.default_rng(42)
   pop = rng.exponential(2.0, 100_000)
   plt.hist(pop, bins=100)
   plt.title("population: exponential — heavily skewed")
   plt.show()
   ```
3. Sample means, three sizes (this cell takes ~20s — that's fine):
   ```python
   means_5 = np.array([rng.choice(pop, 5).mean() for _ in range(10_000)])
   means_30 = np.array([rng.choice(pop, 30).mean() for _ in range(10_000)])
   means_100 = np.array([rng.choice(pop, 100).mean() for _ in range(10_000)])
   ```
   ```python
   fig, axes = plt.subplots(1, 3, figsize=(14, 4), sharex=True)
   for ax, m, n in zip(axes, [means_5, means_30, means_100], [5, 30, 100]):
       ax.hist(m, bins=60)
       ax.set_title(f"means of samples of n={n}")
   plt.show()
   ```
4. Watch the skew die and a bell appear as n grows. That's the CLT, happening.
5. Teach-back markdown, 3 sentences, your words: what the CLT says · why it's the reason confidence intervals work · what it does NOT say about small samples.
6. Save a copy in GitHub, same path, message `feat: runway02 CLT simulation`.
