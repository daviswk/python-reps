## Block C — Notebook 01: the distributions section (60 min)

1. Colab → open `runway01_randomness.ipynb` from GitHub (File → Open notebook → GitHub tab).
2. Markdown cell: `## Distributions`.
3. Cells:
   ```python
   import numpy as np
   import matplotlib.pyplot as plt
   rng = np.random.default_rng(42)
   u = rng.uniform(0, 1, 10_000)
   n = rng.normal(0, 1, 10_000)
   ```
   ```python
   fig, axes = plt.subplots(1, 2, figsize=(10, 4))
   axes[0].hist(u, bins=50)
   axes[0].set_title("uniform(0, 1)")
   axes[1].hist(n, bins=50)
   axes[1].set_title("normal(0, 1)")
   plt.show()
   ```
4. Add the mean lines — one per plot, then re-run:
   ```python
   axes[0].axvline(u.mean(), color="red", linestyle="--")
   ```
   (put the axvline calls before `plt.show()` in the same cell; red dashed = the mean)
5. Labels: `axes[0].set_xlabel("value")`, `axes[0].set_ylabel("count")` — both plots. Ugly is fine; **unlabeled is not**.
6. Markdown cell: one real policy quantity that's roughly uniform · one roughly normal · one that's neither (think incomes — long right tail).
